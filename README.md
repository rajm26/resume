# Raj Mishra — Multi-Page Editorial Portfolio (HTML5 & CSS3 Only)

A complete, 5-page personal portfolio website built for the **IIM Bangalore BBA DBE** web design assignment using **plain HTML5 and CSS3 only (Zero JavaScript, Zero Frameworks)**.

## Multi-Page Architecture
Every navigation link leads to a dedicated, standalone semantic HTML5 page sharing a single `styles.css` stylesheet:
1. `index.html` — **Home & Executive Dossier**: Editorial intro, portrait figure card, 4-column verified metrics ledger, and 3 core practice pillars.
2. `about.html` — **About & Ventures**: Full profile of **Virality360 Private Limited**, **Daijizaiten Horizons Private Limited**, and the 3-stage execution methodology.
3. `work.html` — **Case Studies & Brand Revenue**: Pure CSS brand revenue attribution bar chart, 4-stage conversion funnel diagram, and 8 separate brand case studies (**PW IOI** 74 admissions @ ₹14–14.5L/user, **Aakash BYJU'S** ₹1.70 Cr+, **PhysicsWallah** ₹1.48 Cr+, **Next Toppers “Rakhi Shagun”** campaign, **Adda247** ₹25L, **Vedantu** ₹10L, **Unacademy** 48K+ enrollments, **CK-12 Foundation** 1M+ traffic & 50K+ signups, **Mentor247 / NEET Peak** ₹5L+ & 60K+ community, and **Daijizaiten Horizons** 500+ crawler takedowns).
4. `honors.html` — **Education & National Honors**: Semantic academic table (**IIM Bangalore BBA DBE**, **BKD Aldrich** 9.47 CGPA, **Sacred Heart Centenary Academy** 9.44 CGPA) and awards (**Bharat Ko Jano** National Winner, **Kon Banega Nanha Kalam** Rank #2 out of 48,726 students, **Tagore House Captain** leadership, and **Times of India** Sustainable Goal Changemaker).
5. `contact.html` — **Contact**: Direct institutional email (`raj.mishra26@iimb.ac.in`), LinkedIn (`linkedin.com/in/rajmishra0411`), and a pure HTML5 `mailto:` inquiry form.
6. `styles.css` — **Unified Stylesheet**: Demonstrates CSS Custom Properties (`--variables`), a pure-CSS Light/Dark theme switcher using `#theme-switch:checked ~ .page-shell` (zero JavaScript), CSS Grid, Flexbox, sticky positioning, and responsive media queries.

## How to Host on GitHub Pages
1. Create a public repository on [GitHub](https://github.com/new).
2. Unzip `raj_mishra_github_portfolio.zip` and upload `index.html`, `about.html`, `work.html`, `honors.html`, `contact.html`, `styles.css`, `README.md`, and `raj-mishra.jpeg` to the repository root.
3. Open **Settings → Pages**, select **Deploy from a branch** → `main` → `/ (root)`, and click **Save**.
